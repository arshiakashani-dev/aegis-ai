# Aegis AI

## AI-Powered Disaster Response & Damage Assessment

Aegis is an AI-driven disaster response research and engineering project
focused on rapid post-disaster building damage assessment using
multimodal Earth observation data.

The system aims to transform satellite imagery into actionable
damage intelligence for emergency response and prioritization.
